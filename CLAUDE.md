# S5 Translations

Русские переводы чужих модов сборки S5 (`s5lang`), отдельно от их jar, чтобы обновления модов их не стирали.
Только клиент. Forge 1.20.1, Java 17. Отвечать по-русски.

Устройство: один класс `faygolover.s5lang.S5Lang` (вход); содержимое мода — файлы lang в ресурсах.
- `to_translate/` — что ещё на английском (выгрузка), `translated/` — готовые переводы;
- описание порядка работы — `README.md`.

Как добавить перевод: положить строки в файл lang нужного мода в ресурсах этого мода (не в jar чужого мода),
поднять версию. Переводы своих модов семейства сюда не класть — они живут в самих модах.

Нельзя: править jar чужих модов; переводить JourneyMap (решение Алекса — пропущен).

Сборка: `gradlew.bat build`; проверка: `python ../_family/family.py verify "S5 Translations"`.
